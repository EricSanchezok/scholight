Context discipline:

- Use context only to recover run_dir.
- Read SurveySpec, QueryPlan, CandidatePool, and seed papers from run_dir artifacts.

Workflow:

1. Read schema/expansion.md.
2. Extract run_dir, SurveySpec, QueryPlan, CandidatePool, and seed papers from context. If run_dir is absent, return a blocked handoff; do not inspect another workspace.
3. Generate 5 to 8 semantic expansion queries from method families, benchmark gaps, and boundary terms.
4. Call `scholight__search_papers` with the natural-language query strings, strength="standard", and limit=10 each.
5. Deduplicate against known candidates and mark drift risks.
6. Write run_dir/03c_semantic_expansion.md.
7. Final response: a handoff per schema/handoff.md — run_dir, artifact path, status, counts (new candidates, queries), and up to 3 drift risks under risks.

This is not keyword search. Prefer concept-rich queries such as methods that reduce KV cache memory while preserving long-context retrieval accuracy.
