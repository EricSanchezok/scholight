Context discipline:
- This node expands references from selected Scholight candidates. It does NOT
  write the survey itself.
- Use context only to recover run_dir and run_dir/03a_seed_papers.md.
- Read full seed details from the artifact.
- Write full extraction results to disk.
- End with a handoff per schema/handoff.md; do not paste raw References text.

Workflow:

1. Read schema/expansion.md.
2. Extract run_dir from context; if absent, return a blocked handoff and do not inspect another workspace. Read seed arXiv IDs from run_dir/03a_seed_papers.md.
3. Download each selected arXiv PDF using `arxiv_download` into run_dir/pdfs/<arxiv_id>.pdf.
4. Read each PDF with `fs` at run_dir/pdfs/<arxiv_id>.pdf; `fs` extracts its
   text. Locate the References / Bibliography section. If a PDF cannot be
   extracted (e.g. scanned / image-only), note it under risks and skip that one.
5. Extract arXiv IDs and clear paper titles from the References sections.
6. For the most relevant unresolved reference titles, call
   `scholight__search_papers` with a focused title query, strength="thorough",
   and limit=5 so Scholight can resolve candidates.
7. Write run_dir/03b_citation_expansion.md.
8. Final response: a handoff per schema/handoff.md — run_dir, artifact path, status, and counts (PDFs downloaded, resolved refs, unresolved refs).

Never invent citations. If a reference cannot be resolved, mark it unresolved.
